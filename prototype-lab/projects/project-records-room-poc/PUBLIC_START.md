# Records & Rooms — local prototype

Standalone development prototype for deliberately recorded working discussions,
source documents, artifact references and separately authored notes. This is
not a production meeting service or a completed agent orchestration system.

## Run locally

From this directory, with Python 3.11 or newer:

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python app.py --data-dir /absolute/private/location/records-room-poc-runtime
```

Choose a new data directory outside the repository. It is created owner-private;
an existing directory must have mode 0700. Open http://127.0.0.1:18880 and use
the generated owner-key.txt locally. Do not publish keys or copy runtime files
into source control. Do not expose the development server through a tunnel.
The fixed owner ID `robert` is a prototype implementation constraint, not a
general-purpose account/identity system.

Optional synthetic examples: run `manage.py seed --data-dir` with the same
absolute directory using the virtual environment's Python. No agent is started
by creating a room, inviting a principal or seeding examples.

## Tests

```sh
.venv/bin/python -m pytest -q tests
.venv/bin/python -m pip install -r requirements-browser.txt
.venv/bin/python -m pytest -q tests/browser_checks.py
```

Browser checks require Google Chrome installed locally and permission to start
a loopback listener. They use temporary synthetic records. They are explicit
because `browser_checks.py` is not included in ordinary pytest discovery.
Screenshots generated by those checks are ignored. Connector unit tests use
test doubles; they do not prove participation by a live agent.

## Included and excluded

Included: application, store, CLI utilities, UI, two opt-in development adapter
modules and synthetic tests. `requests` supports adapter imports. Browser
dependencies are separate. Dependency ranges are not a reproducibility lock.

The unapplied `integration/dev_cos_hook.patch` is retained as a fixture read by
an existing connector test; registration does not apply it or install a hook.

Excluded: personal design transcripts, historical review packets, other deployment
patches, provisioning scripts, live-provider probes, credentials and actual
records. Source/test files were copied unchanged for registration. Packaging
changes are limited to dependency declarations, ignores and these public docs.

The gateway responder is NOT the actual OpenClaw-backed Chief of Staff. It is
retained as experimental source, disabled by default and not activated by this
package. No background worker, watcher, production connector or Telegram sender
is installed by registration.
