# IoT Connect history index

IoT Connect carried a previous product name while its standalone beta was being
designed. The two source documents in this directory preserve that design-stage
record exactly as written. Their filenames and contents remain unchanged so the
decision trail stays auditable.

- `CONNECT_HQ_ENGINEERING_DESIGN_REVIEW_2026-09-01.md`
- `CONNECT_HQ_V0_9_BETA_HIGH_LEVEL_SPEC_2026-09-01.md`

Current operating documentation uses the IoT Connect name and technical
identifiers. These retained documents do not define the release configuration.
