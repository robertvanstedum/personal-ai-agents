# Accepted specification

`spec-mini-moi-work-foundation-career-first-ready-to-build--7b0ed6f1.md` is the
accepted specification that governed W0a and W0b. It is preserved here as the
intent artifact in the proof-of-concept chain.

The specification is not rewritten to match the implementation. Declared
implementation divergences and review findings remain in the build handoffs
and Git history. The implementation itself remains authoritative at
`domains/cos/work/`.

The specification's original Planning Studio filename and internal metadata
are retained as provenance. Their presence does not create a runtime or product
dependency on Planning Studio.
