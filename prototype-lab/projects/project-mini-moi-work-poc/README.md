# Mini-moi Work Proof of Concept

This Prototype Lab project records the first Mini-moi Work capability and the
agent-and-Robert delivery method used to create it. Both are being tested in
Guild's `try → prove → keep` loop.

The capability is intended to let Chief of Staff collaborate with Robert on
durable, consequential work without losing sources, authorship, decisions, or
authority. Career cover letters are the first proving ground, not the boundary
of the underlying design.

The project does not duplicate the implementation. Code remains in
`domains/cos/work/`; this folder holds the experiment definition, validation
plan, product vision, case study, and selected evidence chain.

See [START_HERE.md](START_HERE.md) for the current gate and reading order.
