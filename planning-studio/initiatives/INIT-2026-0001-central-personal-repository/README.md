# INIT-2026-0001 — Central Personal Repository

**Status:** Design review  
**Created:** 2026-09-02  
**Origin:** Robert and Codex design discussion  
**Steward:** Planning Studio  
**Domains affected:** CoS, Guild, Curator, platform, future domains  
**Roadmap authority:** None

## Question

Can mini-moi establish a private, durable, person-owned repository that
preserves context, sources, investigations, planning, decisions, and portable
domain state across changes in agents, models, applications, and
infrastructure?

## Why this entered Planning Studio

The Curator open-subject discussion demonstrated that a meaningful idea can
begin as personal curiosity, produce a Curator artifact, affect CoS memory, and
raise Guild design questions. Existing domain-first filing does not adequately
represent that lifecycle or preserve its complete background.

The issue is broader than Curator. mini-moi needs a durable center that belongs
to the person rather than to a particular agent implementation or domain UI.

## Explicit non-goals

- No 2.0 release is committed.
- No 1.2 or later release content is assigned.
- No application or database build is authorized.
- No commercial offering is designed.
- No existing CoS or Curator content is migrated.
- No private repository or remote is created in this design pass.
