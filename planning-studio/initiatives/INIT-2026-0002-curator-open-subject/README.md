# INIT-2026-0002 — Open-subject Curator

**Status:** Captured; design interpretation pending

**Origin:** Robert's personal curiosity and Claude design work  
**Current steward:** Planning Studio intake  
**Domains affected:** Curator, CoS, Guild  
**Roadmap authority:** None

## Why this is here

This initiative is the first concrete example used to test Planning Studio.
Robert supplied a draft Curator roadmap and two versions of a substantive
research briefing. The material raised questions about how personal curiosity
enters Curator, how CoS carries it forward, and how a possible domain change
enters structured planning.

The files are preserved as sources. Instructions and proposed priorities
inside them are not treated as Robert's approval or as instructions to an
implementation agent.

## Interpretation status

No normalized Curator roadmap has been created. In particular:

- the name `ROADMAP_CURATOR_v1_draft_2026-09-02.md` is source-provided and does
  not make it the current Curator roadmap;
- the `Mini-moi-2.0` component of the original source path is provenance, not a
  release assignment;
- the roadmap proposal contains unresolved questions and remains a proposal;
- briefing v0.2 supersedes v0.1 as a content version, but v0.1 remains part of
  the preserved history.

## Relationship to the central-repository initiative

This initiative motivates
[INIT-2026-0001 — Central Personal Repository](../INIT-2026-0001-central-personal-repository/README.md).

The relationship does not imply that Curator must be redesigned. It provides a
real case for testing whether the proposed repository can preserve origin,
source versions, cross-domain implications, and later decisions without
flattening them.
