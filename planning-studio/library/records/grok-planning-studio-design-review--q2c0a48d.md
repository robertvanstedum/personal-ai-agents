## Review disposition

Grok's verdict is **revise, then run the experiment**. The review supports the
person-owned, file-first substrate and recommends a narrower initial slice:

- explicit capture with automated bookkeeping;
- one writer and transactional file publication;
- visible series revisions plus immutable source bytes;
- only the relationships needed by actual records;
- retrieval before CoS write access; and
- no database, graph, UI, registry product, or broad migration in the first
  evidence cycle.

Robert accepted this direction on 2026-09-02, with one timing correction: the
initial evidence cycle will run for two to three weeks, followed by continued
operation. The preserved source's proposed six-month observation period is not
the initial delivery window.
