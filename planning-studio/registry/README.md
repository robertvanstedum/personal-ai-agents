# Registry

The JSON registries are artifacts of the initial v0.1 scaffold. Claude's review
correctly identified that manually maintained registries will drift. They are
therefore non-authoritative while the v0.9 candidate is under review and should
not receive additional manual entries.

The v0.9 candidate proposes generating indexes from record frontmatter. A
generated index must never become the only record of provenance, status, or
decisions.
