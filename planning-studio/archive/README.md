# Archive

The archive preserves inactive, superseded, or discarded Planning Studio
records without showing them as current work.

Archived records retain stable identity, provenance, final status, disposition
reason, and links to replacements when applicable. Archive is not deletion.

The initial manual source manifest is retained under
[`v0.1-scaffold/source_manifest.json`](v0.1-scaffold/source_manifest.json).
It is design history; the current canonical sources and provenance records live
under `library/`.
