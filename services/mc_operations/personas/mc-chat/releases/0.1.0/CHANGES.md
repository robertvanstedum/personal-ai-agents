# Persona 0.1.0

First combined SOUL, portable AGENTS contract, and native runtime binding. Replaces obsolete textual dispatch protocols, the twenty-second investigation cutoff, rigid sentence count, false project filesystem access, and blanket offers with verified per-tool behavior. Includes Board receipt and conditional undo semantics. Public files exclude private snapshots and owner context.

Projection appends this binding and an optional bounded, dated private current-context packet to AGENTS. USER, IDENTITY, memory, conversations, and Board records remain outside the release. Native loading is the first target; container read-only mounts and full record retrieval are later work. This release is a candidate until independently reviewed and authorized for activation; no public push is implied.
