# Private, local and hybrid intelligence — research topic

A dated topic record: where private and local model use stands in mini-moi, set against the field, revisited quarterly. Each snapshot is preserved unchanged after review; the next one is written beside it and links back.

The direction itself is in the repository's architecture (local-first data, model-agnostic operation, a retained local tier). These snapshots record how that direction reads against what is available and proven at a point in time, and what mini-moi has actually measured.
